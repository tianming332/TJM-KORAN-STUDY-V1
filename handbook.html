3.1 韩语句子结构与语法关系

两大基础句子结构

主语 + 谓语
主语 + 宾语 + 谓语

三类扩展句子结构

  • 主语 + 地点／时间状语 + 谓语
  • 主语 + 地点／时间状语 + 宾语 + 谓语
  • 主语 + 间接宾语 + 直接宾语 + 谓语

韩语语法关系主要依靠附着在动词、形容词、名词后面的附加形态表现。附加形态分为两类：助词（名词后使用）和语尾（动词、形容词、叙述格助词后使用）。助词种类：格助词、补助词、接续助词。

3.2 助词系统

3.5 词干、语尾与句子类型

词干：韩语动词、形容词以及叙述格助词原型以 다 结尾，去掉 다 后剩下的部分就是词干。

공부하다（学习）→ 공부하　｜　예쁘다（漂亮）→ 예쁘　｜　이다（是）→ 이

语尾：附着在动词、形容词、叙述格助词词干后，表示句子类型、对听者的尊敬程度等语法意义。语尾只表示语法意义，不表示词汇意义。

语尾类别位置课件说明课件形式
语末语尾／终结语尾句子最后句子终结、句子类型、听者尊敬程度ㅂ니다／습니다；(으)십시오；ㅂ니까?／습니까?
先语末语尾词干与语末语尾之间，通常倒数第二表达时制、主语尊敬等-았／었／였-（过去）；-겠-（将来）；-(으)시-（主语尊敬）
连接语尾句子中间连接两个句子；分类与意义多样课件思维图列出，未展开具体形式
定语语尾句子中间修饰名词，做定语动词：过去 은／ㄴ、现在 는、将来 을／ㄹ；形容词：ㄴ／은；名词：인

终结语尾示例

中文解释：请学习（命令式）

공부하+ㅂ니까? → 공부합니까?（疑问）

中文解释：学习吗？（疑问式）

先语末语尾示例

공부하(词干)+였(过去)+습니다(陈述终结语尾) → 공부하였습니다.

中文解释：学习过了／已经学习了（过去陈述式）

终结语尾阶称页说明：终结语尾阶称表示话者对听者的尊敬程度及亲疏关系，课件以“正式场合／非正式场合”作对照。

3.7 韩语书写基本规则（课件第14—16页）

  1. 单词与单词之间要空格。例：대학교 학생.（大学学生。）
    대학교大学학생.学生
  2. 助词和词尾不空格。作为从属成分的助词和词尾不能与前面的词汇分开书写。例：책을 읽습니다.（读书。）
    책을书（宾语）읽습니다.读（正式）
  3. 数字和单位词要空格。例：한 명（一名），사과 두 개（两个苹果）。表示顺序或习惯性使用的数字可不空格：제이차（第2次）、열두시 삼십오분（12点35分）。
  4. 依存名词与前面的成分要空格。依存名词不能单独使用，必须搭配句子中的其他成分，如 것、바。例：모르는 것은 물어보세요.（请问一下不会的问题。）与指代词一起使用时可以不空格：이것／그것／저것、그분；이것은 책입니다.（这是书。）
    모르는不知道的것은事情／东西（主题）물어보세요.请问
  5. 连接两个单词或列举时使用的词需要空格。例：수학 선생님 겸 담임교사.（数学老师兼班主任。）／사과 포도 오이 바나나가 있다.（有苹果、葡萄、黄瓜和香蕉等。）
    수학数学선생님老师겸兼任담임교사.班主任
  6. 专有名词及专业术语原则上需要空格，但可以不空格。例：상해 공정 기술 대학교／상해공정기술대학교（上海工程技术大学）。
  7. 姓和名之间不需要空格，但姓名和称谓、职务等需要空格。例：왕소명、김 선생님。
  8. 辅助动词原则上要空格，也可以不空格。课件列举：주다、드리다、가다、보다、하다。例：안부를 전해주세요／안부를 전해 주세요.（请转达我的问候。）
    안부를问候（宾语）전해주세요请转达／안부를问候（宾语）전해转达주세요.请给我
  9. 标点符号、大标点符号后面也要空格。例：좋네요! 저도 좋아요.（不错呢！我也喜欢。）
    좋네요!真不错저도我也좋아요.好／喜欢

네／예

课件说明：这是感叹词，不能充当谓语，类似中文回答问题时的“嗯”。肯定回答用 네，否定回答用 아니요。네和예意思相同，네比较常用于亲近关系，예更正式；亲近朋友或晚辈之间，肯定可用응（非尊敬），否定可用아니（非尊敬）。

3.13 短型否定与长型否定

短型否定：안／못

  • 안／못是表示否定的副词，主要用在动词前面。
  • 안表示主观否定，相当于“不做、不想做”。
  • 못表示客观能力否定，相当于“不能做”。
그것은那个东西（主题）안不／못不能사겠습니다.要买（正式）
（不／不能买那东西。）
우유를牛奶（宾语）안不／못不能마십니다.喝（正式）
（不／不能喝牛奶。）
라디오를收音机（宾语）안不／못不能들으십니까?您听吗？
（不／不能听收音机吗？）

强烈否定意愿的表达：안 + 动词词干 + 겠 + 终结语尾。

밥을饭（宾语）안不먹겠습니다.将吃
운동을运动（宾语）안不하겠습니다.将做

名词+하다构成的动词，可以在名词与하다之间加안／못；这种情况下，一般在名词后加宾语助词을／를。

（운동하다=운동을 하다）

长型否定：-지 않다／-지 못하다

  • -지 않다可用于动词、形容词，表示主观否定。
  • -지 못하다只能用于动词，表示客观能力否定。
